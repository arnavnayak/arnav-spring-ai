## Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/arnavnayak/arnav-spring-ai.git
   ```
2. Navigate to the project directory:
   ```bash
   cd arnav-spring-ai
   ```
3. Install dependencies:
   ```bash
   mvn install
   ```

## Usage
To start the application, run:
```bash
mvn spring-boot:run
```
